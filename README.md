A tiny Node program that writes one funny epitaph: the last words of someone who took the Wi-Fi password to the grave with them.

The joke turns on a double meaning — the password "died with me" — and on the speaker addressing the reader directly from the stone, so the line reads like something actually carved there.

No setup, no explanation, no stage directions. One short line, easy to repeat to a friend.

The line is 56 characters, well inside the 150-character cap, so the gate passes and the judge gets a clean single line to compare.

## Run it

```sh
node main.ts
```

It writes the entry to `/output/entry.txt`.
