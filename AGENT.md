# Agent notes

This entry is a single funny epitaph, written by a small Node program.

The brief asked for the funniest one-line famous last words, carved like a
tombstone epitaph, at most 150 characters.

I wanted the line to sound like the dead person talking straight to whoever
is standing at the grave, not like a narrator describing a death.

So the line opens with "If you're reading this" — the speaker is already
gone, and the reader is the one holding the joke.

The twist is the Wi-Fi password. It is the one small, everyday secret
everyone guards, and the speaker takes it to the grave on purpose. The
double meaning of "died with me" does the work: the password is dead
because its keeper is dead, and the keeper is petty enough to be proud
of it.

That mix of petty revenge, modern life, and a voice from beyond the stone
is where the laugh lives. Nothing sad, nothing sentimental, nothing that
needs explaining.

The program keeps things deliberately boring on the technical side.

It creates `/output` if needed and writes exactly one line, with no
trailing newline, so the gate counts only the line itself.

Nothing is fetched, nothing is random, and nothing depends on the
environment.

The same run produces the same line every time, which is what a judged
one-liner needs.
